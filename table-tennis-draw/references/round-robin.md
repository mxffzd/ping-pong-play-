# 组内单循环表

先完成分组，或直接复用既有的 `抽签核验.json`。不要为了加对战表重新运行抽签。

```text
python <skill目录>/scripts/round_robin.py --input <抽签核验.json> --output <新的对阵输出目录>
```

输出 `组内循环对阵.json`、`组内循环对阵.csv`。输出目录必须不存在。JSON 保留分组、参赛编号和组内顺序；`matches` 含比赛编号、组别、轮次、双方编号及姓名，`byes` 单列轮空。

在用表格技能构建或导入工作簿后，可从技能目录绝对路径导入以下函数。该模块不自行发现或安装库，只操作传入的 Workbook：

```javascript
import { addRoundRobinTables } from '<skill目录>/scripts/round_robin_tables.mjs';
const added = addRoundRobinTables(workbook, schedule);
```

模块默认添加两张工作表：

- **循环赛对阵**：按组别、轮次列比赛，黄色格填甲、乙赢得的局数；空白表示未录入。比赛编号稳定，双方相同姓名仍通过编号区分。奇数小组的轮空单列在清单右侧。
- **组内循环表**：每组一个 N×N 矩阵，行、列均显示对应选手姓名；同组重名的列标题另附参赛编号，不使用“1号”等代称。行列同一选手的格显示“—”；比分来自对阵清单，同一比赛的反向格自动交换局数。矩阵按每组原有顺序排列，不另行抽签。

完整的双方非负整数且局数不相等才显示为“已录入”；缺一方显示“待补全”，负数、小数、文本及平局显示“比分无效”。这只是通用录入检查，不代替具体赛事的几局几胜规则。

核验 n(n−1)/2 场、无自身对战、无重复无遗漏、每轮不撞人、奇数轮空覆盖正确；测试空白、单边录入、3:0、平局、负数和小数，并恢复空白。完成后按表格技能重新计算、检查公式、渲染新增视图再导出。
