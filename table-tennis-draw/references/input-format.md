# 分组脚本输入

从原始名单整理为 UTF-8 CSV。必需列 `id,name`；可选列 `affiliation,seed_rank,fixed_group`。

| 列 | 含义 |
|---|---|
| id | 稳定唯一的参赛编号，必填 |
| name | 姓名或完整双打搭档，必填 |
| affiliation | 班级/单位，仅作展示，不自动产生回避约束 |
| seed_rank | 正整数种子名次，非种子留空；有名次不代表自动保护 |
| fixed_group | 用户指定的组号，1至组数；无固定要求留空 |

有同名但编号不同的记录时脚本保留并在核验记录中提示。代理须在执行前完成报名重复核对。

## 聊天输入与脚本参数

用户每次可直接给出“分组个数G、种子个数S、种子人选”，不必自己制作脚本参数或配置文件。把种子姓名与本次名单匹配为唯一参赛编号，核对人数、重复及名单范围；重名时用编号或班级确认。

要求S名种子分别不同组时，确认 `0 ≤ S ≤ G ≤ 有效人数`。在规范名单副本中给这S名选手赋 `seed_rank=1…S`，并调用 `--groups G --protect-top-k S`。人选数量必须正好为S；其他选手不能占用1至S的名次。若用户另有排名或部分保护规则，按其规则保留并核对映射。该编号不表示代理对实力的评价。

S为0时不设受保护种子，人选为空，使用 `--protect-top-k 0`。原始报名资料不修改。把G、S、最终人选及编号列入已有核验记录。

```text
python <skill目录>/scripts/draw.py \
  --input <规范名单.csv> --groups 16 --protect-top-k 8 \
  --output <本次工作区>/outputs/draw-001
```

跨平台按实际 shell 改写换行。`--output` 必须是尚不存在的目录；脚本拒绝覆盖旧抽签。未指定 `--random-seed` 时自动生成重现参数；复现时必须使用相同名单字节、参数、脚本和 Python 版本。

脚本输出：

- `分组名单.csv`：无种子标记的公开名单，Excel 可直接打开；文本字段会防止被当作公式。
- `抽签核验.json`：完整分组、内部种子信息、规则、随机数参数、名单 SHA-256、人数和约束核验、小组单循环对阵清单（非时间赛程）。

仅支持均衡人数、前K名种子不同组及固定组号。超过组数的受保护种子、过满的固定组、固定种子冲突均报错。人数不足以让每组至少有一人时报错，提示调整组数；两人小组或一人小组是否允许由赛事需求决定，不擅自改组。

构造式随机分组不宣称所有合法结果严格等概率。它提供可追溯、可重现的抽签记录，不提供第三方见证或防篡改公证。
